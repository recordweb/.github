# Code of Conduct

RecordWeb adopts the [W3C Code of Ethics and Professional Conduct](https://www.w3.org/Consortium/cepc/) and the [W3C Antitrust and Competition Policy](https://www.w3.org/policies/antitrust-2024) as its community standard, as stated in [`GOVERNANCE.md` §6](GOVERNANCE.md).

All participants — Contributors and Members alike — are expected to adhere to these policies, in every RecordWeb repository and in all associated communication channels (mailing list, calls, issues, pull requests).

## Reporting

Reports of conduct issues should be sent to the Chairs directly via a GitHub issue tagged `[conduct]` in this repository. Such issues are handled confidentially by the Chairs.

If you believe a conduct issue requires the attention of W3C staff, you may instead contact [site-comments@w3.org](mailto:site-comments@w3.org).
